- (insight) Super Admin is fundamentally two distinct tools in one: a fast Operational Triage Cockpit (Support/NOC resolving incidents in seconds) and a Strategic Governance & Monetization Console (Plans, Stripe, Audits, Org Lifecycle). Conflating them creates navigation clutter.
- (insight) The highest-leverage missing capability is Proactive Deliverability & DNS Reconciler: instead of passively displaying DNS records, automatically alerting on drift and providing one-click recovery preserves customer trust.
- (insight) A Command Palette (⌘K) combined with a 360-degree Tenant Hub collapses 80% of current multi-step navigation paths down to single keystrokes.
- (insight) Safety Guardrails (Quarantine sandbox, Two-person tenant purge, Dry-run simulators) transform Super Admin from a high-stress hazardous console into a foolproof, resilient platform.
- (direction) Pillar 1: Modern High-Density Operator UI (⌘K command palette, dark/light theme, slide-over detail drawers, virtualized tables, Zen mode).
- (direction) Pillar 2: Proactive MailOps & Deliverability Engine (Live Stalwart queue inspector, DNS drift reconciler, deliverability scorecard, one-click JMAP test bridge).
- (direction) Pillar 3: Bulletproof Tenant Lifecycle & Governance (Zero-latency tenant impersonation STS tokens, 360 Tenant Hub, safe quarantine sandbox, automated dunning grace periods).
- (direction) Pillar 4: Monetization & Enterprise Superpowers (Custom enterprise overrides, usage threshold heatmaps, bulk migration wizard, exportable diagnostic bundles).
- (decision) Adopt a high-density, command-center architecture organized into 4 clear functional zones: Command Center, Tenant 360 Hub, MailOps & Infrastructure, and Monetization & Governance.
- (decision) Eliminate all modal-in-modal patterns and dead code stubs completely, replacing them with slide-over drawers, inline accordions, and reactive toast confirmations.
- (decision) Preserve existing Toowix Design System 100% intact: keep Indigo/Slate palette, Inter typography, existing CSS variables, and component styles. Do not change colors, fonts, or do a visual redesign; focus strictly on structural gaps, clutter removal, and functional workflow improvements.
